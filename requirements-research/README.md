# Requirements Research Examples

# 

# These screenshots show how students currently organize activities that Campus Buddy aims to improve.

# 

# Campus Events Example

# This screenshot shows the George Mason University event calendar. Students must browse separate event pages to find activities. Campus Buddy integrates event discovery into a centralized student platform.

# 

# Study Group Example

# This screenshot shows a Facebook study group page. Students currently rely on social media groups to organize academic collaboration, which can be unstructured and include non-students.

# 

# Textbook Marketplace Example

# This screenshot shows a textbook buying and selling platform. Students often use third-party websites to exchange textbooks instead of a campus-specific marketplace.

# 

# These examples helped guide the design of the Campus Buddy platform and influenced the development of the core features: events, study groups, and textbook exchange.
